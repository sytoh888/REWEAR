# RE:WEAR — GitHub Pages

This repository hosts the RE:WEAR campus clothing exchange app as a Progressive Web App.

To publish: open Settings > Pages, choose GitHub Actions or deploy from the main branch root, and save. Then open the Pages URL on a phone. Android: Chrome menu > Install app or Add to Home Screen. iPhone/iPad: Safari Share > Add to Home Screen.

The app is a front-end prototype; account, points, uploads, and submissions are demo-only and are not saved to a server.
